# 福よびガチャ — 京都キャラクター版

京都ARカメラの `【アイコン】` 画像を使ったスマートフォン対応のガチャ占いです。ARカメラ本体のコードには変更を加えていません。

## 公開URL

https://lifeislikeamelodies2.github.io/kyoto-ar-camera/fortune-gacha/

## 仕様

- カプセル演出・9キャラクターの登場・口調別の運勢
- 8項目：総評／アドバイス／ラッキーアイテム／ラッキーパーソン／和色のラッキーカラー／創作ネタ／シチュエーション／おすすめ楽曲（YouTubeリンク）
- **芹夢は出現率2％、他8枠は各12.25％**（運勢の吉凶とは独立）
- アイテム・人物・色へのコメントは結果名を繰り返さず、各キャラの経験や人間関係から会話を膨らませる（佐伯と由起緒、藤雨と久坂、以蔵と麻など）
- 佐伯（原作版）は佐伯と共通の関係性・呼称を使用。芹夢は芹沢との思い出だけを語り、芹沢はその相手の名を明言しない
- 創作ネタとシチュエーションを同じカードに並べ、両方を結び付けた一つのコメントを生成
- 音声読み上げでは項目名と結果を一回だけ読み、続けてキャラ本人のコメントを読む
- 以前に保存した履歴も、開き直すと新しい会話表現で表示
- 結果の共有、履歴30件、キャラクター図鑑

## 公開ファイル

- `index.html`：結果画面を含むUI
- `styles.css`：デザイン
- `bundle.js`：圧縮配信データの読み込み処理
- `payload-01.txt`〜`payload-07.txt`：既存アプリ本体のgzip + Base64データ
- `dialogue-v2.txt`：基本の会話強化パック（gzip + Base64データ）
- `character-conversation-v3.js`：キャラクターの関係性・言い回し・創作ネタとシチュエーションを結ぶ会話データ

`dialogue-v2.txt` は編集用ファイルではありません。今回追加した関係性や台詞は `character-conversation-v3.js` を編集してください。基本データそのものを変える場合のみ、`dialogue-v2.txt` の再生成が必要です。

## 注意

- 最近のiOS／Androidのブラウザ向けに `DecompressionStream('gzip')` を使用しています。
- 各キャラクター画像は同じリポジトリの `/images/【アイコン】*.png` を参照し、オンライン環境が必要です。
- 占いは娯楽目的であり、結果はランダムに選ばれます。
